# Client API changelog

**Source of truth:** [`lib/client-api/openapi/changelog.ts`](../../lib/client-api/openapi/changelog.ts) (rendered via [`lib/client-api/openapi/guidePaths.ts`](../../lib/client-api/openapi/guidePaths.ts))

**Live docs:** open `/docs` on the deployed Client API host and select **Guide → Changelog** in the Scalar sidebar.

When adding a release entry, edit `buildChangelogMarkdown()` in the TypeScript module above. Do not edit this file separately — it exists only as a pointer for engineers browsing the repo.

## Editing checklist

1. Update `buildChangelogMarkdown()` in `lib/client-api/openapi/changelog.ts`
2. Bump `CLIENT_API_VERSION` in `lib/client-api/openapi/constants.ts` when the contract changes
3. Run `npm run test:client-api`
4. After deploy, verify `/docs` shows **Guide** (Building campaigns, Changelog, Webhooks) and **API** sections in one sidebar; field-level flow docs live under **Models**

See also [CLIENT_API_DEV_RUNBOOK.md](./CLIENT_API_DEV_RUNBOOK.md).
